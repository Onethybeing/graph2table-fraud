# Context

Independent implementation of a graph-to-table fraud detector, written from the TFM4GAD paper because its repo has no licence. Never copy code from that repo here.

- Results in `results/` come from the private Kaggle kernel `onethybeing/graph2table-fraud-run`, built by `kaggle/make_notebook.py`.
- LimiX rows come from a separate test run of the original code, using the steps in `kaggle/reproduce_upstream.sh`.
- Run third-party code only on Kaggle. Kernels need no token.
- The paper screening and audits live outside this repo, in `fraud-detection-papers`.
